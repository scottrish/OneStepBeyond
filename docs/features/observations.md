# Observations
The following are miscellaneous observations/defects.

## Home
On home page, under 'coming up', it doesn't identify the class, only the assignment title.

Under 'needs attention', only one assignment appears even though there may be multiple due tomorrow.

For the item 'needs attention' if there is no breakdown then 'Break it down' appears. Clicking this takes the user to the assignment editor.  Whereas from Plan the user is offered 'Break down <assignment name>' and Plan <assignment name> as one task instead'. There should only be one experience.

If an assignment does have a breakdown, but it's not been scheduled yet, then 'Find time' appears.  Clicking it takes me to Plan but with no assignments displayed. I have to click Continue to see the list of assignment/tasks, then I can click one or more.

If I click 'Start', I am taken to a page where it also has a 'Start' button along with other assignments for later the same day.  I should not be required to click two 'Start' buttons on different pages.

## Assignments
Does not have a back button that takes you to the previous page.

The breakdown page from Assignments does not let you 'Plan ....as one task instead'.

## Look ahead
Scheduled tasks do not include either class or assignment title.
